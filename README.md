# -# 转啊 · 幸运转盘

一个离线可用的转盘网页程序，所有代码都在 `index.html` 里，不需要安装依赖。

## 打开方式

双击 `index.html`，用 Chrome 或 Edge 打开即可。

## 使用说明

- 点击「新建转盘」创建转盘，名称和选项都可以随时修改。
- 选项一行一个，至少 2 个；重复选项会自动合并。
- 可以创建任意多个转盘，每个转盘独立保存。
- 进入转盘后点击中心按钮开始抽取。
- 已经抽中的选项会在本轮从转盘上移除，不会重复抽到。
- 返回「我的转盘」后再次进入，或者刷新页面，本轮记录会自动清零，所有选项重新回到转盘。

## 数据保存

- 转盘名称和选项保存在浏览器的 `localStorage` 中，下次打开仍然存在。
- 抽取记录只保存在当前页面内存里，不会持久化。
- 清除浏览器的站点数据会同时删除自定义转盘。
- 如果使用隐私模式，或浏览器禁止本地存储，转盘可能无法跨刷新保存。
